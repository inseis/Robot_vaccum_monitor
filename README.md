로봇청소기 편성 월간 취합 프로그램 (robot_vacuum_monitor.py)
==================================================

HD(현대)/GS샵/CJ온스타일/롯데홈쇼핑(LT) 4개 채널의 "로봇청소기" 편성만 걸러서
한 달 치를 자동으로 모아 보여주는 프로그램입니다. 전문 지식 없이도 아래 순서만
따라 하면 됩니다.


1. 맨 처음 딱 한 번만 하면 되는 준비: 파이썬(Python) 설치
------------------------------------------------

이미 컴퓨터에 파이썬이 설치되어 있다면 이 단계는 건너뛰고 "2. 실행하기"로 가세요.

[Windows 사용자]
1) 인터넷 브라우저에서 https://www.python.org/downloads/ 로 접속해요.
2) 가운데에 있는 노란색 "Download Python" 버튼을 눌러요. (자동으로 최신 버전이
   다운로드돼요)
3) 다운로드된 설치 파일을 더블클릭해서 열어요.
4) 아주 중요: 설치 화면 맨 아래에 있는 "Add python.exe to PATH"
   (또는 "Add Python to PATH") 체크박스를 반드시 체크해요. 이걸 안 하면 나중에
   실행이 안 될 수 있어요.
5) "Install Now" 버튼을 눌러서 설치를 끝내요.


2. 실행하기
------------------------------------------------

1) robot_vacuum_monitor.py 파일을 원하는 폴더에 저장해요.
2) 그 파일을 더블클릭해요.
3) 검은색 창(터미널)이 뜨면서 "원하는 달을 입력하세요 (예: 8, 9, 12 / 그냥
   Enter → 이번 달 2026-08):" 라고 물어봐요.
   - 조사하고 싶은 달의 숫자만 입력하고 Enter를 누르면 돼요. (예: 9 → 올해 9월)
   - 그냥 Enter만 누르면 이번 달 기준으로 진행돼요.
4) 잠시 후 메모장(또는 기본 텍스트 편집기)이 자동으로 열리면서 그 달의 로봇청소기
   편성 결과가 날짜순으로 보여요. 맨 아래에는 채널별 방송 횟수, 품목별 방송 횟수
   요약표도 같이 정리돼서 나와요. 이게 끝이에요!

> 결과는 같은 폴더에 텍스트 파일로도 저장돼요. 파일 이름은
> 로봇청소기_편성_YYYYMM.txt 형식이에요. 나중에 다시 보고 싶으면 그 파일을
> 열면 됩니다.

[더블클릭해도 아무것도 안 열릴 때]
- 파일을 마우스 오른쪽 버튼으로 클릭 → "연결 프로그램" → "Python"을 선택해서
  열어보세요.
- 그래도 안 되면, 1단계(파이썬 설치)에서 "Add python.exe to PATH" 체크를
  빼먹었을 가능성이 높아요. 파이썬을 삭제하고 다시 설치하면서 그 체크박스를
  꼭 체크해주세요.
- 인터넷이 연결되어 있어야 정상적으로 데이터를 가져올 수 있어요.

[회사/기관 컴퓨터에서 "인증서" 관련 오류가 날 때]
- 예전에 셀럽PGM 프로그램에서 겪었던 것과 같은 종류의 오류(회사 보안 프로그램이
  HTTPS 통신을 검사하면서 생기는 CERTIFICATE_VERIFY_FAILED 오류)가 나면, 이번
  프로그램은 자동으로 감지해서 우회하도록 이미 만들어 놨어요. 화면에 안내 문구가
  한 번 뜨고 나서 정상적으로 계속 진행됩니다. (내려받는 데이터는 로그인이
  필요 없는 공개 정보라 안전해요) 별도로 해줘야 할 조치는 없습니다.


3. (선택) 매달 자동으로 실행하고 싶다면
------------------------------------------------

Windows의 "작업 스케줄러" 기능에 이 프로그램을 등록하면, 사람이 직접 실행하지
않아도 매달 정해진 날짜에 자동으로 실행되게 만들 수 있어요. 다만 자동 실행 시에는
"원하는 달을 입력하세요"라고 물어보는 대신 자동으로 이번 달 기준으로 진행되고,
결과 파일도 메모장으로 자동으로 열리지 않아요(파일로만 저장됨). 필요하면 설정
방법을 요청해주세요, 화면 캡처와 함께 순서대로 안내해드릴게요.


4. 자주 묻는 질문
------------------------------------------------

Q. 검은 창에서 매번 물어보지 않고, 바로 특정 월로 실행하고 싶어요.
검은 창(명령 프롬프트)을 열고 아래처럼 입력하면 돼요.
    python robot_vacuum_monitor.py --month 2026-09

Q. 결과를 원하는 파일 이름으로 저장하고 싶어요.
    python robot_vacuum_monitor.py --output 9월결과.txt

Q. "(해당 월에는 아직 로봇청소기 편성 데이터가 없습니다)"라고 나와요. 오류인가요?
오류가 아니에요. 원본 사이트(hdmzp.github.io)에 아직 그 달 정보가 올라오지
않았거나, 그 달에 해당 채널의 로봇청소기 편성 자체가 없는 경우예요.

Q. 새로운 브랜드의 로봇청소기가 빠져서 나와요.
robot_vacuum_monitor.py 파일 위쪽의 ROBOT_ONLY_BRANDS 목록에 브랜드명만
추가해주시면 다음부터 자동으로 포함돼요. (예: "로보락", "드리미" 처럼 이름만
쉼표로 추가)

Q. 안마의자/헬스로봇/렌탈 상품이 섞여 나와요.
이번 버전에서는 제품명이나 카테고리에 "안마의자", "헬스로봇", "렌탈"이 들어간
경우는 자동으로 제외하도록 되어 있어요. 그래도 섞여 나오는 게 있으면 예시를
알려주시면 제외 목록에 추가해드릴게요.
